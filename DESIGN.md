# DESIGN.md — LimeNet

Источник правды для интерфейса. Код: `app.limenet.ui.theme` (токены) и `app.limenet.ui.dial` (LimeDial).
Меняется только UI-слой; логика подключения, подписок, разбора узлов и пинга не затрагивается.

## Концепция

Главный экран — долька лайма. Каждый сегмент — один сервер из топ-12 по пингу.
Форма несёт данные и управляет: длина сегмента = качество, обод = остаток трафика,
центр = кнопка подключения. Остальное приложение сдержанное.

Правила: один акцентный цвет. Красный — только ошибки, никогда для успеха.
Тексты поверх акцента — `Bg`.

## Шрифты

Оба OFL, лежат в `composeResources/font`, лицензии в `licenses/`.

- **JetBrains Mono** (Regular, Medium) — цифры и коды: пинг, коды стран, таймер, трафик.
- **Manrope** (Regular, SemiBold) — весь остальной текст.

Roboto и системные шрифты не используются. Material Typography полностью переопределена на Manrope.

## Отступы и радиусы

- Отступы только из шкалы: **4 / 8 / 12 / 16 / 24 / 32** (`Spacing.xs … xxl`).
- Радиусы только: **4 / 8 / 12** (`Radii.s / m / l`). Круги (диск, маркер) — не радиусы.

## Запрещено

Размытие фона (backdrop blur) и тяжёлые тени, декоративные градиенты вне материала «стекло», несколько акцентных цветов,
эмодзи как иконки, стандартные карточки Material, фиолетовый Material по умолчанию.
Ripple на брендовых элементах (LimeDial, центр) отключён.

## Тексты

- Русский, короткие, строчные: «подключено», «отключено», «подключаюсь…», «сессия», «узлов».
- Без «успешно» и «пожалуйста»: успех — «обновлено · узлов: 12», «url-тест · доступно 9 из 12»; ошибка — «не удалось обновить · нет соединения».
- Имя приложения — только константа `APP_NAME` (`app.limenet.ui.Brand`). Не писать строкой.

## Компонент: LimeDial

Размеры считаются от радиуса обода `R`; диаметр циферблата ≈ 80% меньшей стороны, на десктопе не шире 560dp.

**Геометрия.** 12 сегментов, шаг 30°, ширина 27°, зазор 3°. Сегмент 0 в базовой раскладке сверху, по часовой.
Внутренний радиус `0.37R`. Внешний `lerp(0.62, 0.89, quality) · R`,
`quality = 1 − clamp((пинг − 20) / 280, 0, 1)`. Недоступный сервер: quality 0, пунктирный контур.
Свободные слоты (серверов меньше 12): еле заметный контур, сетка 30° сохраняется.

**Обод.** Кольцо на `R`, толщина `0.03R`. Это и датчик: яркая дуга от верха по часовой = остаток трафика
подписки (безлимит или неизвестно = полный круг), остальное — тусклая дорожка. Маркер-точка вверху над выбранным сегментом.

**Цвета и состояния.**
- Выбранный сегмент — сплошной акцент. Остальные — акцент 16% + контур 0.5dp акцент 40%.
- Отключено: тусклый оливковый обод.
- Подключаюсь: короткая дуга бежит по ободу.
- Подключено: дуга обода заливается акцентом (≈500 мс), затем медленная лёгкая пульсация прозрачности. Один проход «волны» по сегментам.
- Анимации: появление долек (волна роста по часовой), плавный доворот к выбранному, плавное изменение длины после замеров.

**Центр** (диск `0.42R`) — кнопка подключения. Тап: подключить / отключить. Лёгкое зажатие (≈300 мс, по ободу диска бежит дуга):
шторка «все серверы», которая вырастает из центра колеса (он же запасной вариант для доступности). Показывает пинг (моноширинный, крупно), страну, мелкий статус сверху.

**Управление.** Вращение перетаскиванием вокруг центра с примагничиванием к ближайшему сегменту, тап по сегменту,
колесо мыши, стрелки (← ↑ предыдущий, → ↓ следующий), Enter/Пробел — центр, `M` — список.
На телефоне — короткий haptic-тик при смене сегмента (где поддерживается).
Вращение меняет только выбранный сегмент. Если подключено, а выбран другой сервер, переключение происходит
только по тапу в центр (в центре тогда «переключить»), никогда молча.

**Данные.** Топ-12 серверов текущей подписки по пингу. Порядок сегментов стабилен: после замеров меняется только длина.
Набор из 12 пересчитывается только при явном обновлении подписки.

**Доступность.** `contentDescription` у центра и у каждого сегмента, управление с клавиатуры.

## Стекло (liquid glass)

Исключение из запрета на градиенты: материал «стекло» для кнопок, плашек, строк и меню (`app.limenet.ui.theme.Glass.kt`).
Без блюра фона — только градиенты, поэтому дёшево для GPU, в том числе на телефонах.

- `Modifier.glass(shape, accent, level)`: полупрозрачная заливка, блик по верхней половине, обводка (светлая сверху-слева, тусклая снизу, лёгкий лайм в дальнем углу).
- `Modifier.pressable(...)`: упругое «вдавливание» + светлая волна от точки касания вместо ripple.
- `GlassBackdrop`: тёмная основа и три размытых лаймовых пятна; стеклу нужно что-то, сквозь что оно светит. Пятна смещаются при перелистывании вкладок.
- Активное состояние — стекло, залитое акцентом (текст `Bg`). Радиусы по-прежнему только 4 / 8 / 12.
- Логотип и данные (длина дольки, пинг) стеклом не затрагиваются.

## Проверка серверов

`Checking.kt` (`app.limenet.desktop.ui`), состояние — `Controller` (`testing`, `checkQueue`, `checkActive`, `checkDone`, `checkTotal`, `checkScope`).

Принцип: пока что-то идёт в фоне, это видно. Приложение не должно выглядеть зависшим, даже если URL-тест длится десятки секунд.

- **Одна кнопка** (`TestButton`): подпись — способ из настроек → стабильность («URL-тест» или «TCP-тест»). Отдельных переключателей способа и кнопки «проверить» нет. Стоит под колесом и в строке поиска списка серверов.
- **Во время проверки** кнопка: вращающееся кольцо, счётчик `5/12` (моноширинный), заливка прогресса акцентом 22%, бегущий блик. Повторный запуск заблокирован до конца.
- **Лента статуса** (`CheckStatusBar`) под поиском в списке серверов: «проверяю · url-тест · <подписка | все подписки>», счётчик и тонкая полоса прогресса с бликом. Появляется и исчезает плавно.
- **Строки серверов:** в очереди — три пульсирующие точки (`PendingDots`), проверяется сейчас — кольцо и блик по всей строке (`scanSweep`), готово — плавная смена на пинг (`Crossfade` 200 мс, ширина поля фиксирована, строка не «прыгает»).
- **Узлы идут через семафор** (URL-тест — 4 одновременно, TCP — 12), состояние обновляется по мере готовности каждого узла. Минимум 700 мс видна анимация, чтобы быстрый TCP-тест не мигал.
- **Область.** Кнопка «тест» у каждой подписки в списке серверов и «Тест» в карточке проверяют только её узлы; «Тест всех» на вкладке «подписки» и главная кнопка — все. Одновременно идёт одна проверка.
- **Итог** — всплывающее сообщение: «url-тест · доступно 9 из 12» или «url-тест · серверы недоступны» (ошибка).

## Обновление подписки

- Значок обновления (`RefreshIconButton`, `RefreshButton`) рисуется кодом, без глифов шрифта: стрелка → вращение (900 мс) → галочка или крестик, рисуются «пером» за ~300 мс → через 1,6 с снова стрелка (`Controller.refreshOutcomes`).
- «Обновить все» показывает «Обновляю…» с кольцом; карточки подписок по очереди крутят стрелку. Итог одним сообщением: все обновились, часть («обновлено 2 из 3», ошибка) или ни одна.
- Причина сбоя — короткая и по-русски: «превышено время ожидания», «нет соединения», «адрес не найден», «сервер ответил 403».

## Всплывающие сообщения

`ToastHost` в корне приложения, поверх экрана и шторки серверов. Строк с сообщениями на экранах больше нет.

- Стеклянная плашка на `Surface` 94%, радиус `Radii.l`, выезжает снизу (260 мс), прячется сама: успех 3,5 с, ошибка 6 с; тап закрывает.
- Успех — акцентная галочка, текст `Text`. Ошибка — красный крестик и красный текст. Красный только для ошибок.
- Отступ снизу: 24 на ПК; на телефоне 16 над нижней панелью.
- Тексты вызываются через `Controller.toast(text, error)`; внутри контроллера — `notify`.

## Навигация

- Вкладки: подключение, подписки, настройки. Переключение — анимированный пейджер (клик или свайп/тачпад), активная вкладка подсвечивается стеклянной плашкой.
- «Все серверы» — не вкладка, а шторка поверх экрана: открывается зажатием центра, закрывается «назад», свайпом вниз по шапке или выбором сервера.
- Настройки: список разделов, у каждой функции своя страница со скольжением (режим, маршрутизация, DNS, стабильность, обновление подписок, разделение трафика, права, логи).

## Первый вход (инструкция)

`Onboarding.kt` (`app.limenet.desktop.ui`). Слой поверх всего приложения, в том числе поверх шторки серверов: затемнение + стеклянная карточка, 5 шагов со скольжением (подписка, колесо, подключение, все серверы, остальное).

- Показывается один раз. Признак — файл `~/.limenet/onboarding-seen`; пишется и при «пропустить», и при «понятно». Закрыли приложение на середине — покажется снова.
- Повторно: настройки → «Как пользоваться».
- Клавиши: → / Enter / пробел — далее, ← — назад, Esc — закрыть. Обрабатываются на корне приложения (`onPreviewKeyEvent`), фокус у колеса не забирается.
- Тексты шагов лежат в `STEPS` в том же файле; про управление колесом должны совпадать с разделом LimeDial выше. Изменили жесты — поправьте оба места.
- Контроллер, подписки и подключение не затронуты.

## Адаптация под телефон

`Adaptive.kt`. Режим «компактный» включается в корне (`LimeNetApp`) по ширине окна: уже 600dp (`COMPACT_MAX`). Читается через `LocalCompact`. На ПК достаточно сузить окно до 360–420dp, чтобы увидеть телефонную раскладку.

- Навигация: вкладки уезжают из шапки в нижнюю панель (три равные стеклянные плашки, 44dp). В шапке остаются логотип, имя и точка состояния.
- Поля экрана 16 вместо 24 (`screenPad()`), нажимаемые элементы не ниже 40dp (`touchMin()`), главная кнопка 44dp.
- Ряды из нескольких кнопок переносятся: режимы и кнопка теста под колесом, ввод подписки, действия карточки подписки (`FlowRow`), действия строки сервера, правила маршрутизации, разделение трафика. Поиск и кнопка теста в списке серверов — в одной строке.
- Строка сервера: скорость url-теста уходит во вторую строку, ★ получает увеличенную зону нажатия. Тап по строке выбирает сервер; меню (выбрать / копировать ссылку / копировать json) — зажатием строки или по трём точкам.
- Карточка подписки: трафик и срок — в две строки; кнопки «Переименовать / Тест / Обновить / Удалить» переносятся по ширине; при переименовании остаются только «Сохранить» и «Отмена».
- Инструкция первого входа: текст шага прокручивается, кнопки остаются на месте.
- Логика, Controller и данные не затронуты: меняется только раскладка.


## User-Agent подписок

Настройки → обновление подписок: «LimeNet», «Happ» или «Incy» (`UserAgentPreset`). Выбранный клиент идёт первым при загрузке подписки, остальные — запасные. Нужен, потому что панели часто отдают список только известным клиентам. Если вместо списка пришла веб-страница, ошибка подсказывает сменить User-Agent. Строки версий лежат в `Settings.kt`.
